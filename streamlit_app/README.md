# Streamlit UI — UNIMAL

Aplikasi utama adalah `streamlit_app/app.py`, dengan identitas hijau-putih Universitas Malikussaleh dan aksen emas. `app_v6.py` serta `app_studio_v7.py` dipertahankan sebagai prototipe historis, bukan entrypoint yang didukung. `inference_engine.py` adalah facade kompatibilitas ke backend modular.

Ekspor CSV prototipe masih menggunakan byte backend tanpa serializer aman aplikasi utama. Gunakan `app.py` untuk berkas pengguna dan jangan arahkan shortcut startup ke prototipe.

Ikuti instalasi Python 3.12 pada [README utama](../README.md). **Startup resmi selalu dari root repository**:

```powershell
.venv\Scripts\python.exe -m streamlit run streamlit_app/app.py
```

Konfigurasi resmi adalah `../.streamlit/config.toml` relatif terhadap folder ini. Konfigurasi lokal `.streamlit/config.toml` memiliki opsi yang sama untuk kompatibilitas; tidak membutuhkan konfigurasi global pengguna. Pengaman aplikasi menonaktifkan ekspor/copy bawaan tabel sebelum UI ditampilkan, termasuk pada startup tanpa konfigurasi. Gunakan tombol Unduh CSV resmi yang melewati serializer aman. Hentikan server dengan Ctrl+C.

Input Teks mendukung prediksi, perbandingan, koreksi, Salin, dan Unduh TXT. Koreksi baru menjadi hasil aktif setelah Terapkan Koreksi; prediksi model tetap tersimpan terpisah. Unggah TXT/CSV memisahkan kartu unggah, daftar berkas berupa baris, Pengaturan Hasil, dan hasil berkas aktif. Pratinjau isi tertutup secara awal. Pilihan kolom CSV tetap per berkas dan memprioritaskan `teks_gundul`; pengguna tetap dapat memilih kolom lain. Proses Diakritisasi memproses ulang berkas aktif, sedangkan Proses Semua hanya memproses berkas valid yang belum berhasil. Penghapusan baris hanya menghapus data sesi. Batasan encoding, mitigasi formula CSV, dependensi Playwright, dan langkah acceptance dijelaskan di README utama.

Setelah memilih **Proses Diakritisasi**, hasil tersusun sebagai status, ringkasan, pilihan tampilan, konten, tindakan salin/unduh, lalu detail opsional. **Arab Berharakat** menjadi default. Pembaca CSV menampilkan maksimal 10 baris per halaman; seluruh kolom dan hasil tetap tersedia pada **Tabel hasil CSV dan metadata**, **Salin CSV**, dan **Unduh CSV**. Salin CSV memakai serializer aman yang sama dengan unduhan.

Pilih **Arab + Terjemahan** untuk langsung membaca pasangan referensi V3 tersimpan yang cocok, termasuk draf, tanpa checkbox tambahan. Pada unggahan, pilihan ini tersedia di **Pengaturan Hasil** sebelum proses dan tidak diulang pada hasil. Mengunggah atau mengubah tampilan tidak menjalankan inferensi. Status verifikasi tidak berubah. Penjelasan bahwa database masih berupa draf berbantuan AI yang belum diverifikasi ahli tersedia di **Tentang Model**. Label draf, ID teknis, catatan sumber, dan Detail Referensi tidak ditampilkan pada kartu hasil; seluruh metadata tetap tersimpan di database dan digunakan oleh validasi. Referensi yang belum tersedia, parsial, atau ambigu diberi keterangan, dan hasil model tetap dapat dibaca. Untuk unggahan dengan padanan parsial, **Hasil Arab lengkap** menyediakan keluaran tersimpan untuk seluruh bagian, termasuk yang tidak mendapat terjemahan. Desktop menempatkan Indonesia di kiri dan Arab di kanan; ruang sempit menumpuk Arab di atas Indonesia. Navigasi atas dan tombol **Sebelumnya/Berikutnya** di bawah membatasi render menjadi satu paragraf untuk Input Teks dan 10 paragraf untuk unggahan, tanpa inferensi ulang. Satu paragraf yang mencakup beberapa segmen tetap utuh. Koreksi manual tetap terpisah dari prediksi asli yang digunakan oleh kartu terjemahan.

Tahap UI-1 mengikuti mockup Input Teks melalui header, sidebar, kartu input/hasil, dan kartu dua bahasa. Logo asli repository dipertahankan; dekorasi ringan dibuat sebagai SVG lokal. Penghitung karakter menampilkan jumlah sebenarnya, tanpa batas total 10.000 karakter yang tidak ada pada implementasi; backend tetap membagi input menjadi segmen maksimal 300 karakter. Tombol **Koreksi Manual** membuka editor yang sudah ada. Tombol **Bersihkan**, hasil asli, dan pengembalian hasil asli tetap tersedia. Halaman Unggah TXT/CSV tidak didesain ulang pada tahap ini.

Pengujian tampilan: jalankan `.venv\Scripts\python.exe -B -m pytest tests -q -p no:cacheprovider`. Runner `.venv\Scripts\python.exe -B scripts/browser_translation_panel.py` menggunakan Edge terpasang, backend asli, CSV Thaharah lokal, dan viewport 1440/1024/768/390 px. Log dan screenshot unggahan terbaru berada di `test-results/upload-redesign/` yang tidak dilacak Git: `upload_1440.png`, `upload_1024.png`, `upload_768.png`, `upload_390.png`, `upload_files_selected.png`, `upload_result_arabic.png`, `upload_result_translation.png`, dan `upload_result_mobile.png`. Pengujian browser juga mencakup navigasi mobile dengan sentuhan, koreksi manual, salin, serta ekspor. Dataset/model lokal tetap diperlukan; tidak ada dependensi atau model baru untuk redesign.

Penyempurnaan hasil memakai metrik aktual, ikon translate di kiri **Terjemahan Indonesia**, serta ikon buku di kanan **Teks Arab Berharakat**. Sidebar menggunakan logo asli di atas nama universitas, dekorasi buku terbuka lokal, dan status kesiapan backend aktual. Badge kitab di kanan atas dihapus. Tombol Proses Diakritisasi pada Input Teks memiliki lebar 248 px di desktop dan boleh memenuhi lebar kartu pada HP. Tidak ada tombol fullscreen dekoratif atau perubahan alur inferensi.

Untuk pemeriksaan khusus Input Teks dan hasil, jalankan `.venv\Scripts\python.exe -B scripts/browser_input_mockup.py`. Runner memakai tiga paragraf Thaharah, termasuk contoh Arab panjang dari referensi desain, dan prediksi model nyata. Screenshot `input_*.png`, `result_*.png`, `translation_*.png`, dan `arabic_*.png` tersimpan di `test-results/result-simplified/` untuk empat ukuran viewport tersebut. Kontrol native Streamlit dan informasi proses nyata dipertahankan sehingga komposisi tidak identik piksel dengan mockup. Folder `test-results/input-mockup/` dan `test-results/result-refinement/` berisi hasil pemeriksaan tahap sebelumnya.

Harakat hasil model perlu diperiksa kembali. Pengujian kesetaraan backend pada sampel tidak membuktikan akurasi atau generalisasi penelitian secara menyeluruh.
